# BigBike Showroom audio

Place one engine sound file for each motorcycle in this folder:

- `ducati-panigale-v4.mp3`
- `bmw-s1000rr.mp3`
- `kawasaki-ninja-h2.mp3`
- `honda-cbr1000rrr.mp3`

## Included source

`kawasaki-ninja-h2.mp3` is "Kawasaki Ninja Burnout" by Hurry_Joe33
(Freesound community), downloaded from Pixabay and listed there for use under
the Pixabay Content License:

https://pixabay.com/sound-effects/technology-kawasaki-ninja-burnout-25333/

Use short, web-optimized MP3 files. The app should reference them through
`import.meta.env.BASE_URL` so they work both locally and on GitHub Pages.
